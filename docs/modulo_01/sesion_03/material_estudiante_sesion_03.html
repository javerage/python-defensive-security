2. Fundamentos Conceptuales de la Sesión

Un registro es una línea de texto que describe un evento: cuándo ocurrió, con qué nivel se escribió y qué datos trae. Antes de usarla hay que limpiarla, porque el relleno de espacios y el salto de línea final corrompen cualquier lectura por posición.

Cómo se lee una cadena en Python (en clase, sin evaluar)

Cada carácter tiene una posición que se cuenta desde cero. El índice 0 lee el primer carácter y el corte [:19] toma los caracteres del 0 al 18 (el 19 queda fuera):

cleaned_log = "2026-09-10 11:15:32 [warn] ..." print(cleaned_log[0]) # Muestra: 2 print(cleaned_log[:19]) # Muestra: 2026-09-10 11:15:32

Si pides una posición que no existe, el programa se interrumpe con IndexError. Por eso primero medimos con len().

📌 Tres precisiones y nada más

Inmutable: ningún método cambia la cadena original en su lugar; cada método devuelve una cadena nueva (por eso existe el TypeError de la sección 5).

find() devuelve una posición: el número donde aparece el texto buscado, o -1 si no aparece. Por eso se compara con != -1 para obtener un sí/no.

Alcance de hoy: en esta sesión trabajamos len(), strip(), índice [0], corte [:19], find(), upper(), replace() y la comparación !=. Nada de índices negativos, startswith / endswith ni decisiones con if (eso llega en la Sesión 04).

Piensa en una etiqueta con polvo en los bordes: nadie lee el código impreso sin limpiarla primero, porque el polvo tapa los primeros dígitos.

Con la línea de registro pasa lo mismo: el relleno tapa la fecha. Primero la limpias con strip(), luego lees por posición ([0], [:19]) y al final muestras cada resultado en su línea del resumen.

5. Clínica de Errores: Lee el Mensaje

Los errores te dicen exactamente qué pasó. Estos son los dos de esta sesión (trazas completas de Python 3.13, con las flechas ^^^^^ que señalan la causa):

🚨 Error 1: IndexError por pedir una posición que no existe
Traceback (most recent call last): File "log_normalizer.py", line 32, in <module> phantom_char = cleaned_log[150] ~~~~~~~~~~~^^^^^ IndexError: string index out of range
Qué pasó:

La línea limpia mide 87 caracteres (posiciones válidas de 0 a 86). Pedir la posición 150 es pedir lo que no existe; Python se detiene en vez de inventar datos.

Cómo se corrige:

Mide primero con len(cleaned_log) e indexa dentro de esa medida.

⚠️ Error 2: TypeError por intentar cambiar la cadena en su lugar
Traceback (most recent call last): File "log_normalizer.py", line 36, in <module> cleaned_log[0] = "#" ~~~~~~~~~~~^^^ TypeError: 'str' object does not support item assignment
Qué pasó:

Las cadenas son inmutables: no se puede cambiar un carácter en su lugar.

Cómo se corrige hoy:

Construye una copia nueva con replace() (como tu sanitized_log).
