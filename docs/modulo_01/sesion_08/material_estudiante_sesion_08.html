2. Fundamentos Conceptuales de la Sesión

Una tupla es un registro sellado: guarda la ficha del analista y nadie puede cambiarla por accidente. Un set es una bolsa sin duplicados ni orden: guarda cada dirección una sola vez para responder "¿cuántas únicas hay?". En la Sesión 07 resumiste conteos con diccionarios; hoy agrupas 20 observaciones: la lista conserva las 20 con sus repeticiones, la tupla protege 3 campos y el set conserva 11 únicas.

Cómo agrupa Python con tuplas y sets (en clase, sin evaluar nada más)

La tupla protege la ficha con paréntesis y no admite cambios:

analyst_record = ("Alex Mendez", "DEF-2026-09", 20)

Con índices lees cada campo: analyst_record[0] es "Alex Mendez" y len(analyst_record) es 3. Intentar analyst_record[0] = "Otro" se interrumpe: la tupla es inmutable.

El set elimina duplicados al convertir la lista:

unique_ips = set(event_ips) ordered_ips = sorted(unique_ips)

Con las 20 observaciones de la práctica, len(event_ips) es 20 y len(unique_ips) es 11: se retiraron 9 repeticiones. El set no tiene orden, por eso se muestra con sorted().

La pertenencia con in clasifica sin conectar nada:

loopback_seen = "127.0.0.1" in unique_ips missing_seen = "10.9.9.9" in unique_ips

loopback_seen es True porque esa dirección sí está en el set. missing_seen es False porque 10.9.9.9 nunca se observó: in pregunta presencia, no conecta nada.

📌 Tres precisiones y nada más

Tupla frente a lista: la tupla no cambia (3 campos sellados); la lista sí cambia y conserva duplicados (20 entradas). Si necesitas corregir la ficha, creas otra tupla: no la editas.

Sets de hoy, nada más: creación con set(), unicidad automática, len(), in y sorted() para mostrar. No hay bucles, no hay comprensión de conjuntos, no hay métodos de diccionario más allá de lo conocido.

Alcance de hoy: 20 datos sintéticos del laboratorio: 7 únicos locales y 4 únicos documentales (192.0.2.0/24). Las etiquetas son didácticas del laboratorio, no estándares universales. Los bucles llegan en la Sesión 09.

EstructuraRegla válida / inválidaEjemplo de la sesión

5. Clínica de Errores: Lee el Mensaje

En Python 3.13, las trazas de error (Tracebacks) señalan la línea y columna exacta de la falla con caracteres ^^^^^. Analiza y resuelve los 2 errores típicos de esta sesión:

🚨 Error 1: TypeError por editar una tupla
Traza real de Python 3.13event_groups.py
File "event_groups.py", line 28, in <module> analyst_record[0] = "Otro nombre" ~~~~~~~~~~~~~~^^^ TypeError: 'tuple' object does not support item assignment
Causa raíz:

La tupla es inmutable: Python señala los corchetes porque ese puesto no admite asignación.

Corrección:

Lee con analyst_record[0]; si cambia la ficha, crea una tupla nueva completa.

⚠️ Error 2: convertir el set a lista y asumir que el índice 0 es estable
Salida sin error… pero con orden falsoevent_groups.py
print(list(unique_ips)[0]) # hoy muestra una, mañana otra: sin orden
Causa raíz:

El set no tiene orden: el puesto [0] no significa "la primera registrada", así que cada ejecución puede mostrar otra.

Corrección:

Muestra con sorted(unique_ips) y cuenta con len(unique_ips).
