2. Fundamentos Conceptuales de la Sesión

Un ciclo anidado revisa una tabla día por día y evento por evento: el ciclo exterior elige el día y el interior recorre sus eventos. El continue salta una línea malformada sin detener el día; el break detiene el día completo cuando aparece la marca de cierre. En la Sesión 09 recorriste una sola lista; hoy recorres 3 días con 6 eventos cada uno y 2 marcas malformadas que se cuentan como omitidas.

Cómo controla Python los ciclos anidados (en clase, sin evaluar nada más)

El exterior elige el día y el interior visita cada evento:

day_total = 0 for day in day_logs: for event in day: if event == "ERROR": day_total = day_total + 1

Con 3 días de 6 eventos, el interior corre 18 veces en total. Cada día deja su subtotal y la suma de los tres es el total general.

El continue salta lo malformado y el break cierra el día:

if event == "UNKNOWN": continue if event == "STOP": break

Con las marcas de la práctica, continue salta 2 UNKNOWN (se cuentan como omitidas) y break detiene el tercer día en STOP: lo que viene después de STOP ese día no se cuenta. No hay else en ciclos en esta sesión.

📌 Tres precisiones y nada más

break frente a continue: continue salta UNA línea y sigue el día; break abandona EL DÍA completo. Si pones break donde va continue, pierdes eventos válidos sin ningún error (verás este caso en la sección 5).

Control de hoy, nada más: anidación de dos niveles, un break y un continue, conteo de omitidas. Sin else en ciclos, sin funciones, sin tercer nivel.

💡 El edificio de tres pisos

Piensa en un edificio de 3 pisos con 6 oficinas por piso: el ciclo exterior sube de piso y el interior toca cada puerta. El continue salta una puerta sin placa; el break cierra el piso cuando ve el aviso de cierre.

Tu programa hace lo mismo: cada piso deja su conteo, las puertas sin placa se cuentan aparte y el aviso de cierre detiene solo ese piso.

5. Clínica de Errores: Lee el Mensaje

En Python 3.13, las trazas de error (Tracebacks) señalan la línea y columna exacta de la falla con caracteres ^^^^^. Analiza y resuelve los 2 errores típicos de esta sesión:

🚨 Error 1: IndentationError por mezclar niveles de anidación
Traza real de Python 3.13matrix_review.py
File "matrix_review.py", line 34, in <module> for event in day: ^^^ IndentationError: expected an indented block after 'for' statement on line 33
Causa raíz:

El for interior quedó al mismo nivel que el exterior: Python esperaba el cuerpo indentado del día.

Corrección:

Indenta el interior un nivel más que el exterior (4 espacios por nivel, sin mezclar).

⚠️ Error 2: break donde va continue, en silencio (sin traza)
Salida sin error… pero con total bajomatrix_review.py
if event == "UNKNOWN": break # detiene el día: pierdes los ERROR válidos que siguen
Causa raíz:

break abandona el día completo, así que los ERROR posteriores a UNKNOWN nunca se cuentan.

Corrección:

Usa continue para UNKNOWN y reserva break solo para STOP.
