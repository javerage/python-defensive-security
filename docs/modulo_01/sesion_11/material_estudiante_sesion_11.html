2. Fundamentos Conceptuales de la Sesión

Una función es una pieza con nombre que recibe datos, devuelve un resultado y no hace nada más. El parámetro es el hueco declarado (events) y el argumento es el valor entregado (event_log). El return entrega el resultado a quien llamó. En la Sesión 10 acumulaste con ciclos sueltos; hoy esas mismas líneas viven dentro de 3 funciones puras que se llaman en orden sobre los mismos 20 eventos.

Cómo define Python sus funciones (en clase, sin evaluar nada más)

Cada función declara, documenta y devuelve:

def count_errors(events): """Return how many ERROR entries the list holds.""" total = events.count("ERROR") return total

Con los 20 eventos de la práctica, count_errors(event_log) devuelve 6. La llamada entrega el argumento; el return devuelve el resultado.

Las tres funciones se encadenan por sus retornos:

error_total = count_errors(event_log) verdict = decide_status(error_total) report_line = format_report(error_total, verdict)

Con 6 errores, verdict es "Revisión prioritaria" y report_line es "Errores: 6 - Revisión prioritaria". Ninguna función imprime dentro: solo devuelven.

📌 Tres precisiones y nada más

Parámetro frente a argumento: el parámetro es el hueco (events); el argumento es el valor (event_log). Si llamas sin el argumento, Python se interrumpe por falta de dato (verás este caso en la sección 5).

Funciones de hoy, nada más: def, return, parámetros posicionales y docstring mínima. Sin ámbitos más allá de lo local, sin *args, sin valores por defecto (llegan en la Sesión 12).

Alcance de hoy: 20 datos sintéticos con 6 ERROR. Las etiquetas son didácticas del laboratorio, no estándares universales. Funciones puras: mismo argumento, mismo retorno.

PiezaRegla válida / inválidaEjemplo de la sesión
defVálido: nombre en minúsculas + parámetros. Inválido: llamar antes de definir.def count_errors(events) → crea la pieza.
returnVálido: devuelve el resultado. Inválido: imprimir en vez de devolver.return total → 6 para quien llamó.
docstringVálido: una línea qué recibe/devuelve. Inválido: sin docstring."""Return how many...""" → documenta la pieza.
LlamadaVálido: argumento por cada parámetro. Inválido: menos argumentos.count_errors(event_log) → 6. Sin argumento → se interrumpe.
💡 La línea de ensamblaje con tres puestos

Piensa en una línea con tres puestos: el primero cuenta piezas defectuosas, el segundo decide el letrero y el tercero arma el cartel. Cada puesto recibe, devuelve y no hace el trabajo del otro.

Tus funciones hacen lo mismo: contar devuelve el número, decidir devuelve el veredicto y formatear devuelve la línea lista para imprimir.

📍 Código en inglés, mensajes en español

Código en inglés por consistencia y colaboración: las variables, funciones y comentarios van en inglés (event_log, count_errors, decide_status, format_report) con estilo PEP 8, para que cualquier equipo pueda leer tu código. Los mensajes que ve el usuario van en español.

Código ordenado en esta sesión: definiciones arriba, llamadas abajo, impresión solo al final. Sin variables globales, sin *args, sin imports y sin archivos ni red.

5. Clínica de Errores: Lee el Mensaje

En Python 3.13, las trazas de error (Tracebacks) señalan la línea y columna exacta de la falla con caracteres ^^^^^. Analiza y resuelve los 2 errores típicos de esta sesión:

🚨 Error 1: TypeError por llamar sin el argumento
Traza real de Python 3.13check_helpers.py
File "check_helpers.py", line 42, in <module> error_total = count_errors() ^^^^^^^^^^^^^^ TypeError: count_errors() missing 1 required positional argument: 'events'
Causa raíz:

Cada parámetro exige su argumento: la llamada no entregó la lista y Python señala la llamada.

Corrección:

Llama con count_errors(event_log): un argumento por cada parámetro.

⚠️ Error 2: imprimir en vez de devolver, en silencio (sin traza)
Salida sin error… pero con Nonecheck_helpers.py
def count_errors(events): print(events.count("ERROR")) # muestra 6 pero devuelve None
Causa raíz:

print muestra y devuelve None: la cadena se rompe porque el siguiente paso recibe None.

Corrección:

Usa return dentro y deja el único print para el final.
