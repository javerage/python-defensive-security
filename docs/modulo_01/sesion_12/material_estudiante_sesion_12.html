2. Fundamentos Conceptuales de la Sesión

Un retorno múltiple entrega dos resultados en un solo viaje: el conteo y su veredicto viajan juntos en una tupla. Un parámetro por defecto propone un valor ("ERROR") que se usa cuando nadie dice lo contrario. El ámbito dice dónde vive cada variable: la local nace y muere dentro de la función, la global vive en el módulo. En la Sesión 11 cada función devolvía un solo valor; hoy una función devuelve dos y el umbral viaja como global de solo lectura.

Cómo devuelve y recuerda Python (en clase, sin evaluar nada más)

El retorno múltiple empaqueta dos valores en una tupla:

def review_events(events, level="ERROR"): """Return count and verdict for the given level.""" total = events.count(level) if total >= 5: verdict = "Revisión prioritaria" else: verdict = "Rutina local" return total, verdict

Con los 20 eventos de la práctica, review_events(event_log) devuelve (6, "Revisión prioritaria") porque el defecto es "ERROR". Con review_events(event_log, "WARNING") el defecto se reemplaza y devuelve (5, "Revisión prioritaria").

El desempaquetado recoge cada valor en su variable:

error_total, error_verdict = review_events(event_log)

error_total es 6 y error_verdict es "Revisión prioritaria". La global REVIEW_THRESHOLD = 5 solo se lee dentro: no se reasigna ni se declara global.

📌 Tres precisiones y nada más

Doble retorno: return total, verdict empaqueta una tupla de 2; el desempaquetado exige 2 variables. Si pides una sola, recibes la tupla completa sin ningún error (verás este caso en la sección 5).

Ámbitos de hoy, nada más: local frente a global de solo lectura y defecto "ERROR". Sin global para reasignar, sin *args, sin clases ni decoradores.

Alcance de hoy: 20 datos sintéticos con 6 ERROR y 5 WARNING. Las etiquetas son didácticas del laboratorio, no estándares universales.

5. Clínica de Errores: Lee el Mensaje

En Python 3.13, las trazas de error (Tracebacks) señalan la línea y columna exacta de la falla con caracteres ^^^^^. Analiza y resuelve los 2 errores típicos de esta sesión:

🚨 Error 1: NameError por leer la local fuera de la función
Traza real de Python 3.13scope_review.py
File "scope_review.py", line 48, in <module> print(total) ^^^^^ NameError: name 'total' is not defined
Causa raíz:

total es local: nace dentro de review_events y no existe en el módulo; Python señala el nombre.

Corrección:

Usa las variables desempaquetadas (error_total) que sí viven en el módulo.

⚠️ Error 2: desempaquetado incompleto en silencio (sin traza)
Salida sin error… pero con tuplascope_review.py
single = review_events(event_log) print(single) # muestra (6, 'Revisión prioritaria'): par sin separar
Causa raíz:

Una sola variable recibe la tupla completa: el par viaja junto y no queda separado.

Corrección:

Desempaqueta con error_total, error_verdict = review_events(event_log).
