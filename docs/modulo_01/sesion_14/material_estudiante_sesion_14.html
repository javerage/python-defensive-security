2. Fundamentos Conceptuales de la Sesión

2.1 Módulo, paquete y la portada __init__.py

Un módulo es un archivo .py con funciones reutilizables (count_kit.py, filter_kit.py). Un paquete es una carpeta que agrupa módulos y que Python solo reconoce como tal si contiene el archivo portada __init__.py: sin esa portada, el import kit falla aunque la carpeta exista. El controlador (pack_review.py) vive fuera del paquete y siempre se ejecuta desde la raíz del proyecto, porque los imports se resuelven desde el directorio de trabajo.

2.2 Las 3 formas de importar y la guardia __main__

Las tres formas alcanzan la misma lógica con distinto alcance: import kit.count_kit trae el módulo completo y exige la ruta larga (kit.count_kit.count_events(...)); from kit.count_kit import count_events trae la función directa y es la más corta; from kit import filter_kit trae el módulo desde la portada del paquete. La guardia if __name__ == "__main__": garantiza que main() solo corre en ejecución directa: si otro archivo importara el controlador, sus funciones llegarían sin disparar el reporte.

2.3 venv, pip freeze y Pydantic anunciado

El venv solo aísla dependencias Python: no es sandbox ni aislamiento de seguridad. La reproducibilidad se prueba en dos pasos: requirements.txt declara el pin compatible (pydantic>=2.0,<3), y pip freeze congela lo realmente instalado (serie 2.x). Pydantic queda hoy instalado y anunciado (import pydantic más versión impresa): ningún modelo se define hasta la Sesión 16, donde llegará BaseModel.

💡 Analogía de Seguridad Defensiva: El maletín del técnico de turno

El técnico guarda cada herramienta en su estuche etiquetado (módulo), los estuches viajan en un maletín con inventario en la tapa (__init__.py), y la lista de repuestos homologados (requirements.txt) garantiza que cualquier compañero reconstruya el mismo maletín. Pedir una herramienta fuera del maletín abierto en la mesa (ejecutar fuera de la raíz) es como pedirla a otra habitación: nadie responde (ModuleNotFoundError).

📍 Principio Pedagógico y Estándar PEP 8 en Inglés

Identificadores 100% en inglés: Conforme al estándar global de la industria y la guía oficial PEP 8, todos los identificadores de variables, constantes, módulos, funciones y comentarios dentro del código fuente se escriben en inglés idiomático (ej. event_log, count_events, filter_kit). La prosa explicativa y el razonamiento analítico se expresan en español.

5. Clínica de Errores y Diagnóstico de Tracebacks

En Python 3.13, las trazas de error (Tracebacks) proporcionan indicadores precisos señalando la línea y columna exacta de la falla con caracteres ^^^^^. Use la lectura de trazas de la Sesión 13 para analizar y resolver los 2 errores típicos sembrados de esta sesión:

🚨 Error Sembrado 1: ModuleNotFoundError por ruta (paquete fuera de alcance)
Terminal — traceback Python 3.13pack_review.py
Traceback (most recent call last): File "/home/alumno/curso-python-defensivo/pack_review.py", line 14, in <module> from kit.count_kit import count_events ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ ModuleNotFoundError: No module named 'kit'
Causa Raíz Técnica:

Python resuelve imports desde el directorio de trabajo: ejecutó desde una subcarpeta (o kit/ no tiene __init__.py), así que el nombre kit no existe en la ruta y el intérprete señala la línea de importación con ^^^^.

Protocolo de Corrección:

1. Mire antes de saltar: dir o ls y confirme kit/__init__.py. 2. Vuelva a la raíz con cd curso-python-defensivo. 3. Re-ejecute con ↑ + Enter.

⚠️ Error Sembrado 2: pip freeze sin venv (Pydantic invisible)
Terminal — traceback Python 3.13intérprete sin venv
PS C:\lab> pip freeze (sin rastro de pydantic en la lista...) PS C:\lab> python -c "import pydantic" Traceback (most recent call last): File "<string>", line 1, in <module> import pydantic ^^^^^^^^^^^^^^^ ModuleNotFoundError: No module named 'pydantic'
Causa Raíz Técnica:

Congeló e importó en el Python global: olvidó activar (.venv) o instaló sin el pin. El freeze muestra otro entorno y el import señala con ^^^^ el paquete ausente.

Protocolo de Corrección:

1. Active el entorno (el prompt debe mostrar (.venv)). 2. Ejecute pip install -r requirements.txt con el pin pydantic>=2.0,<3. 3. Repita pip freeze hasta ver la serie 2.x.
