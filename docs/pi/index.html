Dónde se guardan (local primero)

  • Recomendada para el aula: carpeta local del proyecto <course-folder>/.pi/prompts/ (requiere confiar el proyecto y luego /reload).
  • Alternativa global opcional: ~/.pi/agent/prompts/ (vale para todos tus proyectos). No uses .pi/agent/prompts/ dentro del proyecto.

Qué hace cada comando

  • /nuevo-py: crea un archivo .py con solo el docstring global del curso y comentarios TODO; la solución la escribes tú. Con PRD: /nuevo-py prds/feature_008.md (archivo y sesión del documento). Sin PRD: /nuevo-py demo_practice.py 08 (archivo y sesión dados). No acepta mezcla de 3 args.
  • /check-venv: elige Python instalado, crea .venv con permiso si falta, verifica/activa. No activa tu terminal por ti: copias el comando y lo ejecutas tú.
