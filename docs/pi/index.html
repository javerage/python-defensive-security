Comandos personalizados Pi

Dos guías independientes para crear tus comandos de aula en Pi: preparar archivos Python y verificar tu entorno virtual.

⏱ Tiempo: 15 min por guía 🧰 Prerrequisito: Pi instalado

Elige tu guía

  • Guía de aula • 15 Minutos Crea tu comando /nuevo-py en Pi Prepara el docstring y los TODOs de tu archivo Python; acepta un Markdown opcional y nunca escribe la solución
    Abrir Guía →
  • Guía de aula • 15 Minutos Crea tu comando /check-venv en Pi Verifica si el entorno virtual está activo y muestra el comando de activación según tu sistema
    Abrir Guía →

Qué hace cada comando

  • /nuevo-py: crea un archivo .py con solo el docstring global del curso y comentarios TODO. Si le pasas un Markdown con objetivo y restricciones, lo lee para redactar el encabezado; la solución del ejercicio la escribes tú.
  • /check-venv: comprueba si estás dentro del entorno virtual del curso y te muestra el comando de activación correspondiente a tu sistema. No activa tu terminal por ti: copias el comando y lo ejecutas tú.
