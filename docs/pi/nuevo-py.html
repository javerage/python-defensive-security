Crea tu comando /nuevo-py en Pi

Objetivo: al terminar tendrás el comando /nuevo-py que crea archivos .py con encabezado del curso.

⏱ Tiempo: 15 min 🧰 Prerrequisito: Pi instalado

💡 Concepto en 1 minuto

En Pi, un archivo markdown en la carpeta de prompts se convierte en comando: el nombre del archivo es el nombre del comando (nuevo-py.md → /nuevo-py).

Pasos

  1. Paso 1 — Verifica la carpeta de prompts. Ejecuta en tu terminal: 
    ls ~/.pi/agent/prompts/
    Si no existe, créala con: 
    mkdir -p ~/.pi/agent/prompts/
  2. Paso 2 — Crea el archivo nuevo-py.md en esa carpeta con este contenido exacto: 
    ---
description: Crea un archivo .py nuevo con el encabezado global del curso
argument-hint: <nombre-archivo.py> <sesion> [purpose] [scope]
---

Crea el archivo `$1` con el encabezado estándar del curso.
1. Usa SESSION = `$2` y FILE = nombre base de `$1`.
2. Si faltan datos usa `${3:-Descripción pendiente de la práctica local}` para PURPOSE y `${4:-Localhost authorized testing environment (127.0.0.1 / ::1) only.}` para SCOPE.
3. Copia esta estructura exacta al inicio del archivo (bloque docstring con COURSE: Python for Defensive Security..., REPOSITORY: python-defensive-security | Session $2 (PyDefSec), SESSION, FILE, PURPOSE, SCOPE entre líneas de `===`).
4. Usa identificadores en inglés con PEP 8 (snake_case, UPPER_CASE).
5. Cierra el archivo con `# TODO: implementa aquí`.
  3. Paso 3 — Recarga los comandos en Pi. En Pi ejecuta: 
    /reload
    ⚠️ Sin esto el comando no aparece. Es el error n.º 1 del aula.
  4. Paso 4 — Prueba (predice antes de ejecutar). Antes de pulsar Enter, predice: ¿qué archivo se creará y qué valores tomarán SESSION, FILE, PURPOSE y SCOPE? Luego ejecuta en Pi: 
    /nuevo-py scope_review.py 12
    Verifica que el archivo generado tenga el encabezado completo y cierre con # TODO: implementa aquí. Si ves $1 sin sustituir, avisa al docente.

🎯 Punto de control

Muestra al docente tu archivo generado: debe tener el encabezado completo del curso y la línea final # TODO: implementa aquí. Si aparece $1 literal sin sustituir, algo falló: avisa al docente antes de continuar.

✅ Checklist

  • Archivo nuevo-py.md en la carpeta correcta (~/.pi/agent/prompts/).
  • /reload ejecutado, comando visible y archivo .py generado con encabezado.
