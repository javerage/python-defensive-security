# Ejemplo ilustrativo de guía para agentes (no es configuración activa)

Este archivo es un **ejemplo ilustrativo** de cómo un agente podría orientarse dentro de la **documentación** del proyecto Snake. **No es una instrucción activa de la raíz ni de un cliente**, y no debe renombrarse a `AGENTS.md` esperando que se cargue o se aplique automáticamente: ningún mecanismo lo hace y no se afirma lo contrario.

Tampoco inventa comandos de ejecución, compilación o instalación. **No hay framework elegido ni aplicación implementada**, así que no existen comandos de ejecución o de compilación que documentar.

## Cómo orientarse

Orden de navegación sugerido:

1. Leer [README.md](README.md) para el estado y el índice del contexto.
2. Leer [MISSION.md](MISSION.md) para el propósito y el público.
3. Leer [TECH-STACK.md](TECH-STACK.md) para lo confirmado y lo no confirmado.
4. Consultar [MEMORY.md](MEMORY.md) para hechos aprobados y dudas abiertas.
5. Seguir el plan en [ROADMAP.md](ROADMAP.md) y la entrega en [specs/inicio.md](specs/inicio.md).

## Acuerdos de trabajo

- Seguir los acuerdos de [CONSTITUTION.md](CONSTITUTION.md): honestidad sobre evidencia y aprobación humana explícita.

- No afirmar que el juego funciona, que hay compilaciones o que el arranque está implementado.
- No añadir comandos de ejecución o de compilación que no existan.
